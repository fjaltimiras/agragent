# Contributing to agragent

Thank you for your interest in agragent. Bug reports, questions and suggestions are welcome as GitHub
issues.

## Code contributions and the Contributor License Agreement

agragent is dual-licensed. It is published under the [GNU AGPL v3.0](LICENSE) and is also offered under a
commercial license (see [LICENSING.md](LICENSING.md)). Both are only possible if the copyright holder can
distribute every part of the code under both licenses.

For that reason, a pull request that adds or changes code can only be merged after its author has signed a
Contributor License Agreement (CLA). Under the CLA you keep the copyright in your contribution, and you
grant the project the rights it needs to distribute that contribution under both the AGPL and the
commercial license.

Before you open a pull request with code, write to **contacto@agragent.com** to receive the CLA. Issues,
documentation fixes and discussion do not require it.
